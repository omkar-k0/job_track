Install

Set it up once

Four short steps, then a guided setup in the chat. Nothing runs on this site: Laufbahn installs into Claude Code and keeps its data on your computer.

One-time steps

Checklist

  1. Check the requirements

    • Claude Code 2.1.295 or newer (the Desktop app or the CLI), or Hermes Agent.
    • Node.js 22.18 or newer. If it is missing, /laufbahn:setup offers to install it on macOS and Windows. The tracker uses the built-in node:sqlite module and Node runs the plugin's TypeScript directly, so there are no runtime npm dependencies.

  2. Add the marketplace

    In Claude Code, type:

    /plugin marketplace add omkar-k0/laufbahn

    Using the Claude desktop app instead? Choose Code, select Local and a folder for your job search. Next to the message box open +, Plugins, Add plugin, add the repository https://github.com/omkar-k0/laufbahn as a marketplace, and install laufbahn for your user account.

  3. Install the plugin

    /plugin install laufbahn@laufbahn

  4. Run the setup

    /laufbahn:setup

    A guided conversation. It goes through, in order:

    • your CV, and the hard filters (employment types, hours, enrolment, languages, pay floor, where you can work);
    • soft preferences and writing rules, including the language to write in;
    • accounts, including which calendar your interview invites land on;
    • connectors and a browser check;
    • sources: which job boards and employer pages to read, with German ones first if you are searching in Germany;
    • autonomy: review each application yourself (the default), or let it apply automatically to matching roles;
    • the weekday schedule and how the daily report should reach you;
    • a calibration run of five results, so you can say "no, because..." and teach it your taste.

    It never asks for passwords or ID numbers, and it tells you where your personal data is stored before saving any of it. You can stop at any point and run /laufbahn:setup again to resume. Already tracking in a markdown table? /laufbahn:import <folder> brings it in.

  5. Connect what helps (recommended)

    • Gmail and Google Calendar connectors, for recruiter replies, interview invites and reply drafts.
    • A browser: Claude in Chrome or the host's built-in browser, for logged-in job boards, employer pages and application forms.
    • Optional: a LinkedIn MCP server, used read-only for job search and inbox.

    Without a browser the daily sweep still runs on connectors and the tracker alone. Work that needs a browser is queued, and the report says so.

Alternative

Hermes Agent

Use Hermes Agent instead of Claude Code? Clone the repository and run the installer:

git clone https://github.com/omkar-k0/laufbahn.git
cd laufbahn
plugin/scripts/hermes-install.sh

Restart Hermes and type /laufbahn:setup. The installer registers the tracker as a server named job_hunt_tracker and checks that Hermes saved it. Known differences, such as a weaker stop gate in unattended runs, are listed in the Hermes guide.

After setup

The daily commands

Once the weekday task is scheduled, /laufbahn:sweep runs by itself. These are the commands you type.

CommandWhat it does
/laufbahn:sweep [--limit N]The daily run. Applies only when you enabled auto-apply; otherwise it never submits.
/laufbahn:statusPipeline summary and open items.
/laufbahn:boardThe board in your browser: kanban or table, search, filters and stats.
/laufbahn:apply [role-id]Verify, write, fill, read back, then submit automatically if enabled or wait for your approval.
/laufbahn:approve <role-id>You type this on the filled form to allow one submit attempt.
/laufbahn:cover-letter <role-id>A cover letter, optionally as a one-page PDF.
/laufbahn:prep <company>Interview prep from your own stories.
/laufbahn:correctTurn an override of yours into a rule, with a reason and an example.
/laufbahn:allow-consentApprove consent boxes for one specific application form.
/laufbahn:triage <source>Reconcile and clean a tracker board, behind the delete guard.
/laufbahn:setupReconfigure or resume setup.

Ask Claude in any chat for follow_ups, funnel_stats or export_data. They read your local tracker only, and exports are written to ~/.laufbahn/exports/ only when you ask.
